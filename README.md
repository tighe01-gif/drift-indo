# Indo Explorers

Premium landing page for **Indo Explorers** — Indonesia's first mobile scuba diving and adventure expedition company.

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide Icons
- shadcn/ui components

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Enquiry API

Submissions are stored locally in `data/enquiries.json` via `POST /api/enquiry`.

## Deploy

Deployed on Vercel. Push to `main` to trigger automatic deployments.
