# Drift Indo

Premium landing page for **Drift Indo** — Indonesia's first mobile adventure expedition company.

**Live:** [https://indo-explorers.vercel.app](https://indo-explorers.vercel.app)

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide Icons
- shadcn/ui components

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Waitlist API

Submissions are stored locally in `data/waitlist.json` via `POST /api/waitlist`.

## Deploy

Deployed on Vercel. Push to `main` to trigger automatic deployments.
